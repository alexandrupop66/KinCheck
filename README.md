\# KinCheck



> \*\*AI can clone their voice. It can't clone your history.\*\*



KinCheck is an AI-assisted identity verification prototype built for \*\*ForgeHacks 2026 — AI + Cybersecurity\*\*.



Modern impersonation scams can imitate writing style, voices and personal details. KinCheck takes a different approach: instead of trying to detect whether content was generated by AI, it compares a suspicious message with the relationship history the user already knows.



\## The idea



A user imports a standard WhatsApp `.txt` conversation with a trusted person.



KinCheck builds a lightweight relationship fingerprint from signals such as:



\- primary language

\- communication style

\- common emoji

\- known relationship context

\- shared conversational history



The user can then paste a suspicious message.



A deterministic identity engine compares that message with the established baseline and produces one of three outcomes:



\- \*\*IDENTITY MATCH\*\*

\- \*\*VERIFY\*\*

\- \*\*HIGH RISK\*\*



For messages that require verification, KinCheck can also use Gemini to generate a \*\*Private Challenge\*\* based only on explicit facts found in the shared conversation history.



The system never needs to know the answer. The trusted person does.



\## Core principle



\*\*AI proposes. Deterministic rules decide.\*\*



Gemini does not assign the identity verdict.



The deterministic KinCheck rule engine calculates the verdict using explicit signals such as:



\- language change

\- unexpected new phone or number

\- unusual financial request

\- urgency

\- greeting mismatch where baseline data exists



This means the identity verdict remains available even if the AI service is unavailable.



\## Private Challenge



When enough shared history exists, KinCheck can generate a private verification question.



Example:



Conversation history:



> We complained about the fish at a restaurant in Corfu.



Valid challenge:



> What did we complain about at the restaurant in Corfu?



Invalid challenge:



> What was the name of the restaurant?



The restaurant name was never present in the conversation.



KinCheck includes a grounding guard that requires the AI to provide supporting evidence copied from the source conversation. Ungrounded challenges are rejected.



\## Graceful degradation



KinCheck is designed so that Gemini is an enhancement, not a dependency for the identity verdict.



If Gemini is unavailable:



\- the deterministic verdict remains valid

\- the risk score remains visible

\- the user is advised to verify through a separate trusted channel



If there is not enough shared conversation history:



\- KinCheck does not call Gemini

\- no private challenge is invented

\- the interface explicitly reports that more shared history is required



\## Privacy and security



KinCheck keeps the Gemini API key on the server side.



The following processing happens locally in the browser:



\- WhatsApp parsing

\- relationship fingerprint generation

\- deterministic identity analysis

\- risk scoring

\- verdict generation



When a Private Challenge is requested, the imported conversation is sent through the KinCheck backend to Gemini for relationship-evidence extraction.



The included demo conversation is synthetic.



No login, database, WhatsApp API, banking API, voice processing or real-time monitoring is used.
